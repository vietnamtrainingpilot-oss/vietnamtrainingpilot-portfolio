Netlify (Recommended):
  1. Push code to GitHub
  2. Go to Netlify.com
  3. Click "Import from Git"
  4. Select your repo
  5. Build: npm run build
  6. Publish: dist
  7. Deploy!

Vercel:
  1. Push to GitHub
  2. Go to Vercel.com
  3. Import project
  4. Auto-detects settings
  5. Click Deploy

GitHub Pages:
  1. npm run build
  2. Push dist/ to gh-pages branch
  3. Enable in repo settings
