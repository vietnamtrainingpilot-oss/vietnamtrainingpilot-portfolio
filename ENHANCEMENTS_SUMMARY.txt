🎬 THE 12 PERFORMATIVE UI COMPONENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 1. ScrollProgressBar
    → Gradient bar at top showing scroll position
    → Updates in real-time as you scroll

 2. AnimatedCard
    → Cards fade in, lift up, glow on hover
    → Used for stats in About section

 3. FloatingElement
    → Continuous up-down floating animation
    → Used for in-progress projects

 4. GradientText
    → Text with animated gradient background
    → Highlights key phrases

 5. CounterText
    → Numbers count up (0 → target)
    → Used for: 2 communities, 3 bots, 100+ events

 6. ParallaxSection
    → Content scrolls at different speed
    → Creates depth effect

 7. StaggeredList
    → List items animate in sequence with delay
    → Each item has staggered entrance

 8. RotatingBox
    → Continuously rotating container
    → Used for bots section

 9. PulseBorder
    → Border pulses with glow effect
    → Draws attention to important content

10. SlideInText
    → Text slides in letter-by-letter
    → Used for section headings

11. HoverScaleButton
    → Button scales & glows on hover
    → "Copy Discord Handle" button

12. ProgressBar
    → Animated progress bars
    → Visual representation of stats
