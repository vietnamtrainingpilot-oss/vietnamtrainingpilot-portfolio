## Design System at a Glance

### Colors (OKLCH — Perceptually Uniform)
```
Dark Theme (Primary):
--color-base:        oklch(9% 0.02 280)      # Deep navy
--color-accent:      oklch(60% 0.25 45)      # Warm orange/gold
--color-accent-2:    oklch(65% 0.28 180)     # Cyan

Light Theme (Fallback):
--color-base:        oklch(98% 0.01 280)     # Off-white
--color-text-primary: oklch(15% 0.02 280)    # Deep navy
```

### Typography
```
Serif (Editorial):  Crimson Text 400 (h1, h2, h3)
Sans (Body):        Inter 400-600 (body, buttons)
Mono (Technical):   JetBrains Mono 400 (code, tags)
```

### Spacing
```
Base increment: 4px
Scale: xs(12px), sm(14px), base(16px), lg(18px), xl(24px), 
       2xl(32px), 3xl(48px), 4xl(64px), 5xl(88px)
```

### Animation Easing
```
Entrance:  cubic-bezier(0.34, 1.56, 0.64, 1)  # Overshoot bounce
Reveal:    cubic-bezier(0.4, 0, 0.2, 1)       # Smooth ease-in-out
Hover:     cubic-bezier(0.68, -0.55, 0.265, 1.55)  # Elastic
```

### Option 1: Netlify (Recommended) ⭐

**Setup (2 minutes):**
1. Go to [netlify.com](https://netlify.com)
2. Click "Add new site" → "Import an existing project"
3. Connect your GitHub repository
4. Build command: *(leave empty)*
5. Publish directory: `.` (root)
6. Deploy

**Result:** Live at `https://your-site.netlify.app`
**Bonus:** Auto-deploys on every git push

### Option 2: Vercel

**Setup (2 minutes):**
1. Go to [vercel.com](https://vercel.com)
2. Click "Add New..." → "Project"
3. Import GitHub repository
4. Framework: `Other`
5. Deploy

**Result:** Live at `https://your-site.vercel.app`

### Option 3: GitHub Pages

**Setup (5 minutes):**
1. Push repository to GitHub
2. Go to repo Settings → Pages
3. Select branch: `main`
4. Select folder: `/ (root)`
5. Save

**Result:** Live at `https://username.github.io/vietnamtrainingpilot-portfolio`

### Option 4: Self-Hosted (Any Server)

Copy `index.html` to your web server. No build step. Done.

## Quick Customization (If Needed)

### Change Colors
Edit the CSS variables in `<style>`:
```css
:root {
    --color-accent: oklch(60% 0.25 45);  /* Change this */
}
```

### Update Content
Edit HTML directly in the content sections (hero, cards, timeline, etc.)

### Add More Websites/Bots
Copy a `<div class="card">` block and update the title, description, link

### Modify Animations
Edit keyframes (`@keyframes float`, `revealUp`, etc.) or durations
